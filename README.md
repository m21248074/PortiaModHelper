# Portia Mod Helper

A multi-functional Unity mod integration project developed for *My Time at Portia*. This project is managed using the latest `.slnx` solution architecture and contains multiple independent sub-projects.

## Module Feature List

* **AchivementHelper**
  * Achievement helper mod to track or optimize the progression of in-game achievements.

* **BetterFactory**
  * an upgraded standalone quality-of-life mod based on the original **[BetterFactory](https://www.nexusmods.com/mytimeatportia/mods/131)** mod. While preserving the original's excellent factory management optimizations, this enhanced version introduces a highly requested feature: **Customizable Production Speed Boosts**, allowing your late-game automated factories to run faster and more efficiently than ever before.

* **CaiQuan Master**
  * a lightweight quality-of-life mod for *My Time at Portia* that ensures you will **always win** the Rock-Paper-Scissors (Roshambo) mini-game against any NPC, no matter what choice you or the NPC make.

* **CatchCow Master**
  * Completely revamps the tedious cow-catching mini-game into a high-speed, fully automated score farm. No more aiming, clicking, or missing—sit back and watch your points skyrocket effortlessly anytime you play!

* **Favor Helper**
  * Unlimited play/date and party modifier! Instantly freezes your action points to the absolute maximum, expands available event counts, and completely eliminates the cooldowns for repeating dates and organizing parties.

* **Fishing Master**
  * The ultimate companion for fishing! Features intelligent auto-reeling tension control, flawless automatic bubble tracking, and dynamic drop rate adjustments tailored to your fishing rod tier.

* **GoBang Divine Move**
  * A "God's move" predictor for Five-in-a-Row (Gomoku). It clones the board and forces the native AI to calculate your best placement. This mod is currently withheld from Nexus because it causes white stones to erroneously overwrite existing pieces on the board.

* **Relic Manager**
  * This mod is an enhanced version built upon the original [Relic Manager](https://www.nexusmods.com/mytimeatportia/mods/39) mod. This update brings full Traditional Chinese localization, optimized list sorting, and introduces two major features: "Relic Piece Exchange" and "Piece Gambling". Players can now perform a 1:1 swap for duplicate pieces, or spend Gols to roll for missing pieces from specific ruins, significantly reducing the late-game relic collection grind!

* **Rich Shop**
  * Expands store funds! Automatically injects +100,000 gold into every merchant's cash pool whenever shop money generates, allowing you to bulk-sell your expensive late-game items without running merchants broke.

### Standalone External Tool

* **AddMoreItemsToShopEditor**
 * a standalone, lightweight WPF desktop application companion tool. It is specifically designed to visually edit the configuration files generated by the popular mod **[Add More Items to Shop](https://www.nexusmods.com/mytimeatportia/mods/147)**, allowing you to effortlessly add any in-game item into specific stores of *My Time at Portia*.

## Development & Build Guide

### Prerequisites

1. Visual Studio 2026

2. .NET Framework 3.5

3. Unity Mod Manager (UMM) 0.32.4

### References

Before building, ensure the following .dll files from the game directory are added to your project references:

- Assembly-CSharp.dll
- UnityEngine.dll / UnityEngine.CoreModule.dll
- UnityModManager.dll
- 0Harmony.dll

### Build Steps

1. Clone this repository
2. Open PortiaModHelper.slnx using Visual Studio 2026.
3. Right-click the desired project and click Build.
4. Copy the compiled .dll alongside the Info.json into the game's Mods' directory.

## Installation & Usage

1. Ensure Unity Mod Manager (UMM) is installed for My Time at Portia.
2. Copy the compiled mod folder (containing .dll and Info.json) to your mod path, like `C:\Program Files (x86)\Steam\steamapps\common\My Time at Portia\Mods\`
3. Launch the game, press Ctrl + F10 to open the UMM interface, and verify the mod status is green.
